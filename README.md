# Khan IT - Digital Marketing Agency Landing Page

A modern, high-performance landing page for **Khan IT**, a leading digital marketing agency in Bangladesh. Built with **React 19**, **Tailwind CSS 4**, and **Vite**, this project features a clean, professional design with dynamic blog routing and interactive components.

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge)](https://deluxe-sundae-08e368.netlify.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/nomayen31/khan-it-landing-page-)

## 🚀 Live Demo
Check out the live site: [https://deluxe-sundae-08e368.netlify.app/](https://deluxe-sundae-08e368.netlify.app/)

## ✨ Features
- **Dynamic Blog System**: Interactive blog section with dedicated routes for individual articles.
- **Modern UI/UX**: Premium design with smooth transitions and responsive layouts.
- **Service Showcases**: Detailed sections for SEO, Web Design, Ads, and Branding.
- **Interactive Process Flow**: Visualized "How We Deliver" process section.
- **Case Studies**: Real-world examples of client growth and success.
- **Responsive Design**: Fully optimized for desktops, tablets, and smartphones.
- **Lucide Icons**: High-quality, scalable vector icons.

## 🛠️ Tech Stack
- **Frontend**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: JavaScript (ES6+)

## ⚙️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/nomayen31/khan-it-landing-page-.git
   cd khan-it
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
